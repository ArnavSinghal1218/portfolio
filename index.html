M.Sc. Master's Thesis Spotlight

Evaluating Fourier Layers in DeepPET Architecture

Forward Modelling of the 2D Helmholtz Equation • Universität Heidelberg (2023 - 2026)

The Scientific Challenge & Solution

Simulating forward wave-field propagation modeled by the 2D Helmholtz equation is computationally prohibitive with traditional numerical solvers (e.g. finite difference methods). While standard deep learning architectures struggle with phase dispersion and localized receptive field limits, this thesis engineered an FFT-augmented U-Net (DeepPET) integrating spectral convolution layers with hybrid fusion and skip connections.

Spectral Convolutions

Performs parameterized tensor multiplications directly in the 2D Fourier domain, learning global receptive fields with quasi-linear complexity.

Hybrid Skip Fusion

Fuses high-frequency spatial boundary features with spectral phase representations across the U-Net hierarchy.

Physics-Aware Metrics

Validated using multi-mode evaluation in TensorBoard tracking phase error, wavenumber conservation, and velocity distributions.

Quantitative Superiority

Achieved a 34% lower mean relative error and 62% validation loss reduction over standard baseline models.

Core Stack: Python PyTorch torch.fft TensorBoard GCP Compute
Benchmark Comparison Verified on Held-out Sets

Error Reduction vs. Standard U-Net

Standard U-Net Baseline: 100% (Baseline Error)
DeepPET (Fourier FFT Layer): 66.0% (-34% Relative Error)
Validation Loss Baseline: 1.00x Loss
DeepPET Fourier Augmented: 0.38x Loss (-62% Loss Drop)
Target PDE Governing Equation
\(\nabla^2 u(\mathbf{x}) + k^2(\mathbf{x}) u(\mathbf{x}) = f(\mathbf{x})\)
Where \(k(\mathbf{x}) = \omega / c(\mathbf{x})\) represents spatially heterogeneous acoustic velocity fields.
